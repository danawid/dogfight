# Dogfight — Lab 01: ігровий цикл

Космічний корабель на canvas, яким можна літати по арені. Симуляція працює з фіксованим
кроком (рівно 60 кроків/с на будь-якому моніторі), рендер з інтерполяцією між двома
останніми станами.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run check      # Prettier + ESLint
```

Потрібен Node 22 (див. `.nvmrc`).

## Керування

| Клавіша     | Дія                      |
| ----------- | ------------------------ |
| ← → або A D | поворот                  |
| ↑ або W     | тяга                     |
| H           | сховати/показати HUD     |
| R           | записати статистику 10 с |

## Структура

```txt
src/
  main.js           збирає все докупи, режими експериментів
  loop.js           createLoop(): rAF + акумулятор, статистика
  input.js          createInput(): клавіатура як замикання (isDown, justPressed)
  sim/ship.js       integrate(ship, controls, dt): чиста функція, без DOM
  sim/arena.js      арена 1600×900 і "загортання" країв
  render/canvas.js  canvas з урахуванням devicePixelRatio
  render/draw.js    інтерполяція, фон, корабель, HUD
```

`src/sim/` не може використовувати `window`, `document`, `performance` і `Math.random`:
це перевіряє ESLint (`eslint.config.js`).

## HUD

- **steps/s**: скільки разів за секунду викликалась симуляція (має бути 60 завжди).
- **frames/s**: скільки кадрів намальовано (частота монітора).
- **кадр**: мс між двома кадрами; у дужках час, який зайняв сам кадр.
- **джитер**: стандартне відхилення часу кадру за останні 120 кадрів.
